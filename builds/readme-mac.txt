Install VSTForx
---------------
    - just extract the whole zip file content into your VST directory.
      
      after that your VST Folder should contain:
			\VSTForx              <- VSTForx folder
			\VSTForx\vstforx.vst  <- VSTForx FX plugin file
			\VSTForx\vstforxInstrument.vst <- VSTForx instrument plugin file

Configure VSTForx
-----------------

    - open your favourite Host / Sequencer Application and load VSTForx.
    - open the contextmenu and select "Open Setup Dialog"
    - add your VST directory/ies
    - press Ok.
    - don't forget to repeat this procedure when your directory content has changed !



Checkout "http://www.vstforx.de" for new versions.
