\kap{Module}
VSTForx bietet eine Reihe verschiedener Module, die in den Signalweg eingebunden werden können.
Prinzipiell kann zwischen drei Modultypen unterschieden werden:
\begin{itemize}
	\item Signal verändernde Module
	\item Signalwegschalter
	\item Signal nach Parameterwert Umwandler
\end{itemize}
Alle Module lassen sich über das Kontextmenü bedienen.
Rufen Sie einfach das Kontextmenü dort auf, wo sich das gewünschte Modul befindet. 
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\ukap{Das Plugin}
VSTForx ist in der Lage beliebig viele Audio-Plugins (siehe Kapitel \ref{compatible} auf Seite \pageref{compatible}) zu laden und in den Signalweg einzubinden. Durch Betätigen des (\includegraphics[scale=0.5]{../graphics/e}) Schalters im Plugin-Knoten kann (falls vorhanden) das Plugin-Editor Fenster geöffnet werden. Das Plugin kann dort auf herkömmliche Art und Weise bedient werden. 
\\\\
\aktion{MIDI Eigenschaften}
	Ist das entsprechende Plugin in der Lage MIDI-Daten zu empfangen, erscheint ein Untermenüpunkt \untermenupunkt{midi properties}. Der Signalweg hat keinen Einfluss auf die MIDI-Daten Verteilung in VSTForx. Alle in VSTForx eingehenden MIDI-Daten werden an alle empfangsbereiten Plugins weitergeleitet. Um MIDI-Daten gezielt an ein Plugins zu leiten, muss eine MIDI-Kanal Einstellung an den betreffenden Plugins erfolgen. Über den \emph{'midi-channel'} Parameter lässt sich dem Plugin ein MIDI-Kanal zuordnen. Einstellbar sind die Werte: \emph{0..16 sowie 'all'}.
\aktion{Plugin Parameter}
	Im Untermenü \untermenupunkt{Plugin-Name Parameter} befinden sich alle Plugin Parameter.
\aktion{Plugin Programme}
	Im Untermenü  \untermenupunkt{programms} sind - falls vorhanden - die entsprechenden Pluginpresets auswählbar.
\aktion{Plugin-Editor Eigenschaften}
 Im Untermenü \untermenupunkt{editor window} befinden sich alle Plugin-Editor Parameter:	
 	\bParameterlist
		\param{editor\_X}{0}{1}{X-Position des Editor-Fensters}
		\param{editor\_Y}{0}{1}{Y-Position des Editor-Fensters}
		\paramSw{editor\_open}{closed}{open}{sichtbarkeit des Editor-Fensters}
	\eParameterlist

\ukap{Volume}
The Volume module is a signal processor. It contains a single parameter which allows to control the volume of the incoming signal.
\aktion{Module Parameter}
	\bParameterlist
		\param{Volume}{0}{1}{volume}
	\eParameterlist

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\ukap{Pan}
Like the Volume module, the Pan module is a signal processor with a single parameter. Use it to control the panning of the incoming signal.
\aktion{Modul Parameter}
	\bParameterlist
		\param{Pan}{0}{1}{pan}
	\eParameterlist

\ukap{Input / Output Switches} 
Input / Output Switches are able to switch between several states while every state belongs to an input respectively to an output. An "Input Switch" for example can switch several inputs to one output. A "selector" parameter controls the switch state. Furthermore several parameters control the "fade-in / fade-out" behaveiour.
\aktion{Adding States}
	To add an additional switch state you can find a respective option in the context menu of any switch object.  
\aktion{Module Parameter}
	\bParameterlist
		\param{selector switch}{0}{1}{the state selector}
		\param{fade-in duration x\stern}{0ms}{1000ms}{''fadein'' duration x}
		\param{fade-in curve type x\stern}{type1}{type\sstern}{''fadein'' slope type x}
		\param{fade-out duration x\stern}{0ms}{1000ms}{''fadeout'' duration x}
		\param{fade-out curve type x\stern}{type1}{type\sstern}{''fadeout'' slope type x}
	\eParameterlist
\stern : x=the related state \\
\sstern : see figure \ref{curvetypes} on page \pageref{curvetypes}

\ukap{Input/Output Step Switches} 
Unlike the "I/O Switches" the "Step Switch" state is not controlled by a parameter. The states will be iterated automatically. Either with a \emph{fixed} time per state or \emph{synced} to the beat of the current DAW.\\
\\\\
\tip{%Wann der Syncmodus die Stepsequenz beginnt, ist abhängig davon, an welcher Taktposition in der Hostanwendung die Start-Taste gedrückt wurde. Gestartet wird immer an dem nächst liegenden Viertelnotenwert.
Heads Up! In sync mode the state position will be reseted on incoming "play" event of the DAW. }
\aktion{Adding States}
	To add an additional switch state you can find a respective option in the context menu of any switch object.   
\aktion{Module Parameter}
	\bParameterlist
		\paramSw{Step Type}{fix}{sync}{Der Step Modus}
		\paramRe{Step x duration\stern}{10ms}{1000ms}{1/128}{1/1\sstern}{duration x}
		\param{fade-in duration x\stern}{0ms}{1000ms}{''fadein'' duration x}
		\param{fade-in curve type x\stern}{type1}{type\ssstern}{''fadein'' slope type x}
		\param{fade-out duration x\stern}{0ms}{1000ms}{''fadeout'' duration x}
		\param{fade-out curve type x\stern}{type1}{type\ssstern}{''fadeout'' slope type x}
	\eParameterlist
\stern : x=the related state \\
\sstern : see figure \ref{curvetypes} on page \pageref{curvetypes}

\ukap{Das Peaktracker Modul}
Das Peaktracker Modul gehört zu den ''Signal nach Parameterwert Umwandler''. Diese analysieren das anliegende Eingangssignal und senden das Ergebnis an einen Ausgabeparameter. Somit ist es möglich, Plugin- sowie Modulparameter über ein Audiosignal zu steuern. Im Falle des Peaktracker Modules wird das anliegende Audiosignal direkt in einen Parameterwert umgewandelt. Signalausschläge wie zum Beispiel bei einer Snaredrum würden direkt an den Ausgabeparameter übertragen.

\aktion{Modul Parameter}
	Der Untermenüpunkt \untermenupunkt{peak\_tracker parameter} enthält folgende Parameter:
	\bParameterlist
		\param{offset}{0}{1}{verschiebt den Augabeparameter}
	\eParameterlist

\ukap{Das ADSR-Trigger Modul}
Das ADSR-Trigger Modul gehört ebenfalls zu den Signal nach Parameterwert Umwandlern. Ähnlich herkömmlicher Synthesizer wird hier eine ADSR-Sequenz (siehe \ref{adsr} auf Seite \pageref{adsr}) ausgelöst. Nur mit dem Unterschied, dass diese Sequenz nicht durch einen Tastendruck ausgelöst wird, sondern durch das anliegende Eingangssignal. 
\\\\
Am Eingangssignal liegt ein Schwellwert-Trigger. Ist ein Schwellwert überschritten, startet der ADS-Teil der Sequenz. Wird der Schwellwert wieder unterschritten, geht die Sequenz in den R-Teil über.\\

\ukap{Das MIDI-Daten-Empfänger Modul}
Das MIDI-Daten-Empfänger Modul empfängt MIDI-Kontrolldaten und überträgt dessen Werte an die jeweiligen Parameter.
\aktion{MIDI Eigenschaften}
Genau wie bei den (MIDI-fähigen) Plugins lässt sich über den Untermenüpunkt \untermenupunkt{midi properties} der MIDI-Empfangskanal einstellen.
\aktion{Modul Parameter}
Im Untermenüpunkt \untermenupunkt{midi\_receiver parameter} befinden sich alle 127 MIDI-Control + Pitchbend Parameter.
