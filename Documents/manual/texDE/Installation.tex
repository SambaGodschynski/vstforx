\section{Installation}
\subsection{Systemvoraussetzungen}
\subsubsection{Windows}
	\paragraph{Hardware}
		\begin{itemize}
			\item Pentium/Athlon Prozessor mit 500Mhz oder schneller
			\item 512MB RAM
			\item 20MB freier Speicherplatz auf der Festplatte
			\item Eine mit Windows XP(SP3)/Vista/7 kompatible Soundkarte
		\end{itemize}
	\paragraph{Software}
		\begin{itemize}
			\item Windows XP(SP3)/Vista/7
			\item Eine VST2.x kompatible Hostanwendung
		\end{itemize}
\subsubsection{Mac}
	\paragraph{Hardware}
		\begin{itemize}
			\item Apple PowerPC/i386 500Mhz oder schneller
			\item 512MB RAM
			\item 40MB freier Speicherplatz auf der Festplatte
			\item Core-Audio kompatible Audioschnittstelle
		\end{itemize}
	\paragraph{Software}
		\begin{itemize}
			\item MacOs 10.4.0 oder höher
			\item Eine VST2.x kompatible Hostanwendung
		\end{itemize}
\subsubsection{Unterstützte Pluginformate}
Derzeit wird lediglich das VST2.x Pluginformat in der 32-bit Variante unterstützt.

\subsection{Installation}
Entpacken Sie, je nach Betriebsystem, den Inhalt der Datei ''VSTForx-\forxVersion-win.zip'' oder ''VSTForx-\forxVersion-mac.zip'' in das VST-Pluginverzeichnis Ihrer Hostanwendung.
\\\\
Öffnen sie Ihre Hostanwendung und vergewissern Sie sich, dass VSTForx korrekt von ihrer Hostanwendung erkannt wurde (die genaue Vorgehensweise hierfür ist abhängig von ihrer Hostanwendung). 
\\\\
VSTForx sollte in zwei Varianten erscheinen:
\begin{itemize}
	\item VSTForx (als Effekt)
	\item iVSTForx (als Instrument)
\end{itemize}

\subsection{Das Scannen}
\paragraph{Hinzufügen von Pluginverzeichnissen}
Mittels der Schaltflächen \emph{''add Directory''}, \emph{''change Directory''}, \emph{''remove Directory''} können Sie vorhandene Pluginverzeichnisse zur VSTForx-Plugindatenbank \emph{hinzufügen}, \emph{ändern}, oder \emph{entfernen}. Der Scanvorgang startet nach betätigen der ''Ok'' Schaltfläche, sobald ein Verzeichnis hinzugefügt oder geändert wurde. Andernfalls können Sie jederzeit durch 
betätigen von ''scan now'', den Scanvorgang initiieren. \\ 
\paragraph{Der Scanvorgang} 
VSTForx durchsucht nun alle Pluginverzeichnisse nach kompatiblen Plugins (siehe Unterstützte Pluginformate). Die Ergebnisse dieses Vorganges werden in einem weiteren ''VSTForx Scan Directories''-Dialog angezeigt. Während des Scanvorgang ist - Systembedingt - keine Interaktion mit der VSTForx Oberfläche möglich. Es wird daher empfohlen zu warten bis der Scanvorgang vollständig abgeschlossen ist. Dies kann, je nach System, mehrere Minuten dauern. Ist der Scanvorgang beendet wird eine Zusammenfassung im ''VSTForx Scan Directories''-Dialog angezeigt (Siehe Abbildung \ref{scanres}).
\\\\

\paragraph{Fast Scan}
Während des Scanvorgangs sucht VSTForx alle Dateien, die als Plugin infrage kommen\footnote{je nach System handelt es sich dabei um ''.dll'' oder alle ''.vst'' Dateien}. VSTForx versucht dabei diese Dateien als Plugin zu laden. Dies kann je nach Plugin und System mehrere Sekunden dauern. Sollte der Scanvorgang zu lange dauern oder es zu Abstürzen kommen, besteht die Möglichkeit das Laden der Plugins zu überspringen. Aktivieren Sie hierfür die ''Fast Scan'' Option.
\\\\
Ist die ''Fast Scan'' Option aktiviert, werden alle potentiellen Plugindateien ungeprüft in der Plugindatenbank aufgenommen. Allerdings besteht dabei die Gefahr, dass Dateien die für VSTForx nicht ladbar sind, in die Plugindatenbank aufgenommen werden.
