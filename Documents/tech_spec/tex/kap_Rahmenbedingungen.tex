\section{Rahmenbedingungen}

\neupunkt{R}

\punkt{R} Das System ist eine VST-2.3 Plugin Anwendung.
\punkt{R} Zielplattform ist Windows ab XP sowie MacOS ab 10.4 (PowerPC/i386)
\punkt{R} Das System wird von DAW Systemen, die VST2.3 unterstüzen, als Plugin geladen und ausgeführt.
\punkt{R} Hardwarevorraussetzungen: ein Windows oder Mac Computer, auf dem eine Ziel-DAW lauffähig ist.
\punkt{R} Zielgruppe sind Anwender, die Kenntnisse in der Audioverarbeitung und Klangerzeugung haben. Außerdem haben sie umfangreiche Kenntnisse im Umgang mit einer DAW Software.
\punkt{R} Das System ist eine Anwendung, die Audiosignale in Echtzeit bearbeitet.
