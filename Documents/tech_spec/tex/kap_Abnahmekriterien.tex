\section{Abnahmekriterien}
\neupunkt{A}

\punkt{A} Gültiges Abnahmeszenario: 
	\begin{itemize}
		\item VSTForx in einem DAW Projekt als Effekt öffen.
		\item VSTForx ein VST-Pluginverzeichnis mit 1000 Dateien durchsuchen von denen 100  keine VST-Plugins sind.
		\item 10 Plugins in VSTForx öffnen.
		\item Plugins als Effektkette einbinden: 5 in Serie, 5 parallel
		\item alle Plugin Editoren öffnen und auf Funktionalität prüfen
		\item Plugin Parameter als Drehregler anzeigen und auf Funktionalität prüfen
		\item Parameter Veknüpfung prüfen
		\item Parameter Veknüpfungsoperatoren prüfen
		\item Zusätzliche Module auf Funktionalität püfen
	\end{itemize}
