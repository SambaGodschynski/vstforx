It's done!

After almost a year of work VSTForx has a completely new vector oriented User Interface which increases the workflow dramatically. Besides that, it builds the "easy extendable" base for all future implementations. (This was a major disadvantage of the old VstGui implementation)

VSTForx's new GUI



Three Actions One Mouse Button

What was approached with three mouse states before, can now be done with the object itself.
The problem, which appears especially when using knobs, is that we can do three actions: moving, using and connecting. But we have only one mouse button!
(The right mouse button is for translating the view. Modificator keys such as “shift” or “ctrl” are problematic because there is lack of keyboard support in some host applications.)


The solution to this problem is the “coroa” field. When you hover over an object this “corona” field appears. There are “two” corona types:



  • The Node Corona

    The I/O node corona which is a single (yellow) field around a node. With draggin this yellow zone you are able to move the node around. Connecting will be approached by dragging the mouse over the node itself.

  • The Knob Corona

    The knob corona is a double sided field (red/yellow) around a knob. The yellow side is still for moving the knob. The red side is for connecting the knob with another knob. To manipulate (use) the knob just use the knob as expected.



The Scene Browser

Another inconvenient element was the context menu. Finding several plugins in a complex folder structure could be really annoying. The context menu now is almost for opening the “Scene Browser” only. With the “Scene Browser” you are able to:

  • navigate through the scene tree
  • add plugins
  • add modules
  • manipulate plugin/module parameter
  • add plugin/module parameter to view
