It's finally done!

After almost a year of work VSTForx has a completely new vector oriented User Interface which increases the workflow dramatically and particularly build the "easy extendable base" for all future implementations (this was a major lack of the old VstGui implementation).

Three Actions One Mouse Button

What were approached with the three mouse states before, can now be done with the object itself. The problem especially for knobs is that we can do three actions with it: moving, using and connecting. But we have only one mouse button ( the right mouse button is for translating the view, modificator keys like “shift” or “ctrl” are problematic because the lack of keyboard support in some host applications)

The solution for this problem is the “coroa” field. When you hover over an object this “corona” field appears. There are “two” corona types:

  • The I/O node corona which is a single (yellow) field around a node. With it you are able to move the node. Connecting will be approached by dragging the mouse over the node itself.
  • The knob corona which is a double sided field (red/yellow) around a knob. The yellow side is still for moving the knob, the red side is for connecting the knob with another knob. To manipulate (use) the knob just use the knob as expected.

The Scene Browser

Another inconvenient element was the context menu. Finding several plugins in a complex folder structure could be really annoying. The context menu now is almost for opening the “Scene Browser” only. With the “Scene Browser” you are able to:

  • navigate through the scene tree
  • add plugins
  • add modules
  • manipulate plugin/module parameter
  • add plugin/module parameter to view
